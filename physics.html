音速公式

a = √(γRT/M) = 331.3 × √(1 + T/273.15) m/s

音速由介質的彈性與密度決定，跟聲音大小完全無關。溫度越高分子動得越快， 傳遞擠壓的接力越快 → 音速越快（每升 1 °C 約 +0.6 m/s）。

聲音在不同東西裡跑多快？

聲音是「分子推鄰居」的接力，所以越硬（彈性模數大）、越輕的介質傳得越快。固體通常最快，氣體最慢。

介質音速 (m/s)是空氣的幾倍聲音跑 1 km 要幾秒備註
為什麼吸了氦氣聲音會變高？ 氦氣很輕（密度只有空氣的 1/7），音速快到約 970 m/s。 聲帶振動頻率沒變，但聲道的共振頻率 ∝ 音速，共振被推高，聽起來就變成卡通聲。

🌌 光速是宇宙的速限

c = 299 792 458 m/s 是定義值——1 公尺就是「光在 1/299792458 秒走的距離」。 任何帶質量的東西加速到 c 需要無限能量，所以 c 到不了、更超不過。

🕐 看遠方 = 看過去

太陽光到地球要 8 分 20 秒，所以你看到的太陽是 8 分鐘前的樣子。 看 4.24 光年外的比鄰星，看到的是 4 年多前的它。

🐢 光在介質裡會變慢

v = c/n。在水裡 (n=1.33) 剩 22.5 萬 km/s，鑽石 (n=2.42) 只剩 12.4 萬 km/s。 「變慢」正是折射與散射的根源 → 見下一頁。

為什麼會轉彎？——「行軍過泥地」模型

🚶 一排人斜著走進泥地

先踏進泥地的那一側先變慢，整排人的方向就被拉向接近法線的方向。 光的波前完全一樣：進入慢介質（n 大）就往法線偏，進入快介質就遠離法線。

⏱ 費馬原理

光走的是時間最短的路徑，不是距離最短。在慢介質裡少走一點、在快介質裡多走一點， 總時間反而更短 —— 折射角就是這樣被決定的。

🔒 全反射

從慢往快（如水→空氣），入射角大過 θc = asin(n₂/n₁) 時折射角算不出來， 光 100% 被反彈回去。水面下往上看會看到史奈爾窗；光纖、鑽石的火光都靠這招。

聲音也會折射

折射不是光的專利，只要波速在空間中變化就會發生。音速隨溫度變化，所以：

  • 夜晚聲音傳得遠：地表冷、上空暖（逆溫），上方音速快，聲線被往下折回地面，能量不容易散失到高空。白天相反，聲音往上折走，遠處就聽不清。
  • 海洋 SOFAR 聲道：約 1000 m 深處音速最低，聲線被上下兩側折回這一層來回反射，鯨魚叫聲可以傳幾千公里。
  • 沙漠蜃景的聲學版：熱地面上空音速梯度大，會出現「聽得到卻聽不清方向」的區域（聲影區）。

空氣分子比光的波長小很多（約 0.3 nm vs 500 nm），屬於瑞利散射：越短的波長被彈開得越厲害。
  • 白天天空藍：陽光在頭頂上方被空氣分子四面八方彈散，彈得最多的藍光從各個方向進入你眼睛。（不是紫色，因為太陽的紫光本來就少、大氣高層吸收，加上人眼對紫不敏感。）
  • 夕陽紅：太陽貼近地平線時，陽光要斜穿約 38 倍厚的大氣，藍綠光沿路幾乎全被散射掉，只剩紅橙光直達你眼睛。
  • 太空中的天空是黑的：沒有空氣可以散射，看不到太陽以外的光。

顆粒變大 → 換一種散射

🔵 瑞利散射（顆粒 ≪ λ）

空氣分子。強烈偏好短波長（1/λ⁴）→ 天空藍、夕陽紅。

⚪ 米氏散射（顆粒 ≈ λ 或更大）

雲滴、霧、灰塵、牛奶。各波長散射量差不多 → 雲是白的、霧是白的、霾讓天空變灰白。

🌊 吸收 ≠ 散射

深海的藍主要不是散射，是水吸收紅光（水對紅外／紅光吸收強）。同一杯水很淺看不出顏色， 幾十公尺深才藍得明顯。

丁達爾效應（看得見的光路）

乾淨空氣裡看不見光束，因為沒有東西把光彈進你眼裡。灑點粉塵、起霧、或在水裡滴幾滴牛奶， 光束就現形了 —— 你看到的是被散射到側向的那部分光。舞台的光柱、森林裡的耶穌光都是這樣來的。

小實驗：一杯水滴 2 滴牛奶，手電筒從側面照。側面看是淡藍（短波長被散射到側面）， 正對光源看透過去的光是橙黃（藍被散射走了，剩長波長穿過）—— 這就是一杯水裡的日出與日落。

⛵ 船：重心 G 與浮心 B

船傾斜時浮心 B 會移到傾斜的那一側，產生把船扳回來的力矩。 關鍵是穩心 M（metacentre）：
GM = KB + BM − KG，BM = I/V。
GM > 0 → 會自己回正；GM < 0 → 一傾就翻。復原力臂 GZ = GM·sinθ。

貨物往高處堆 → KG 上升 → GM 變小 → 側翻風險大增。壓載水艙就是刻意在船底加重、壓低 KG。

🏠 家具 / 書架

同樣的公式：地震時地面加速度超過 g·(B/2)/Hcg 就開始搖擺傾倒。 窄高的書架臨界值最低 → 一定要用 L 型鐵件鎖牆，並把重物放下層降低 Hcg。

為什麼不倒翁不會倒？ 重心極低而且底部是圓弧：一傾斜，重心反而被抬高，重力就把它推回最低點。 「穩定平衡」的定義就是：偏離之後位能上升。

升力的真正原因（順便破除一個流傳很廣的錯誤說法）

❌ 常見錯誤：「等時通過」

「上表面比較長，空氣要同時到後緣，所以走得快、壓力低。」
錯在哪：沒有任何物理定律要求上下的空氣同時抵達後緣。實測上表面的空氣比下表面早很多到達。 而且平板機翼（上下一樣長）照樣有升力，倒飛的飛機也飛得起來。

✅ 說法一：動量（牛頓第三定律）

機翼把大量空氣持續向下偏折（下洗流）。空氣獲得向下的動量，反作用力就把機翼往上推。
L = 每秒被推下去的空氣質量 × 向下速度。攻角就是控制偏折多少的旋鈕。

✅ 說法二：壓力（伯努利＋流線彎曲）

流線繞著上表面彎曲，維持彎曲需要向心力，於是垂直流線方向出現壓力梯度：靠近上表面壓力低。 搭配 p + ½ρv² = 常數，低壓處流速快。上下表面壓力差乘機翼面積就是升力。

兩種說法是同一件事的兩種算法，不是互相競爭的理論。

前面學的在起飛時怎麼用上
密度 ρ升力正比於 ρ。熱天、高原機場空氣稀薄 → 同樣速度升力較小，跑道要更長。這叫密度高度。
大氣壓力ρ = P/(R·T)。氣壓低（高海拔、低氣壓天氣）→ ρ 小 → 性能下降；同時引擎吸進的空氣少，推力也跟著掉。
加速度a = (T − D − μ(W−L))/m。滑行是活生生的 s = ½at²：a 只要小 10%，需要的跑道就長 11%。
浮力（對照組）飛機不是靠浮力（機身排開的空氣重量只有幾百公克，遠小於幾十噸）。升力是動態產生的，必須有速度；熱氣球才是純浮力。
重心重心必須落在允許範圍內。太後 → 抬頭失控甚至失速；太前 → 抬不起前輪。裝載平衡表（W&B）是起飛前的必算項目。
音速巡航時 M ≈ 0.85；再快局部氣流就超音速產生震波。這決定了後掠翼與巡航速度上限。
水壓／流體壓力皮托管量的是動壓 ½ρv²，飛機的空速表就是靠它。管子結冰堵住 → 空速表讀數錯誤，是多起空難的原因。
折射／散射散射決定了跑道能見度（霧＝米氏散射）；跑道燈的顏色與可見距離、以及低角度陽光刺眼，都是這一頁的內容。
光速雷達、GPS、雷射測距全靠光速已知且固定。GPS 靠 c 把時間差換成距離，誤差 1 微秒 = 300 公尺。
