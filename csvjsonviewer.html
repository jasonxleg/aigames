📑 資料檢視器CSV / JSON · 欄位內含 JSON 也讀得懂

📂
把 CSV 或 JSON 檔拖進來
支援 .csv .tsv .json .ndjson .jsonl .txt
可一次拖多個檔 — 每個檔案一個分頁，搜尋／排序／篩選各自獨立（Ctrl+Tab 切換、Ctrl+1~9 直達）
CSV 的分隔符號（, ; Tab |）與編碼（UTF-8 / Big5）都會自動判斷；
欄位值若是 JSON 字串 會自動辨識，可點開看樹狀、也能一鍵展開成欄位。
大檔 OK：超過 8MB 會邊讀邊解析（實測 200MB／百萬列可用），先載前 50 萬列，要全部再按一下。
🔒 檔案完全在你的瀏覽器裡處理，不會上傳到任何伺服器。
