② 判斷結果

    ③ 選用：AI 複判（Gemini）

    本地規則只看得到字面線索；「待確認」那批可以交給 Gemini 再讀一次職缺內文。金鑰只存在這台電腦的瀏覽器。

    判斷規則與執行紀錄

    ✅ 可以：寫明 worldwide / anywhere / globally remote / any time zone、APAC / Asia / GMT+8，應徵地區清單含台灣或亞洲，或地點就在台灣（104 等）。

    🤔 待確認：有遠端字樣但沒限制地區。排序時加分：自由接案/外包、需要中文、地點在新加坡/澳洲/日本等時區相近處；扣分：實習/應屆、同時寫 hybrid、地點只寫英國。

    ❌ 不行：應徵地區清單不含台灣（例如 Remotive 的「USA Only」、Himalayas 的國家清單）、Remote (UK/US/Australia/Singapore)、需要當地工作權/公民/PR、限 EMEA/歐洲/美洲，或完全沒有遠端字樣（等於要進辦公室）。

    🎮 只看遊戲相關：只套用在 Remotive / Jobicy / Himalayas 這類綜合職缺站；gamesJobs、104 搜尋結果全部顯示。

    remote play / remote config 這類技術名詞不算遠端。列表通常沒有完整職缺說明；看到「待確認」可以點「貼內文重判」，把原文貼進來再判一次。
