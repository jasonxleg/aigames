選擇 Google Drive 資料夾

⚙️ 設定

取得方式：Google Cloud Console → API 和服務 → 憑證 → 建立憑證 → OAuth 用戶端 ID → 類型選「網頁應用程式」→ 「已授權的 JavaScript 來源」加入本頁網址的來源（例如 ）。 並在「已啟用的 API」開啟 Google Drive API。
因為要讀寫你 Drive 裡「既有」的檔案，本工具要求完整的 Drive 權限（auth/drive）。 若 OAuth 應用程式在「測試」狀態，使用者的 Gmail 要先加入測試使用者清單。
Client ID 只存在這台瀏覽器（localStorage），不會寫進程式碼。
