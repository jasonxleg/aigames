🧠 AI 會議摘要

⚙️ 設定

「會議聲音」辨識、AI 摘要需要它。到 Google AI Studio 免費申請。金鑰只存在本機瀏覽器 localStorage，不會寫進任何檔案。會議音訊會送到 Google Gemini 處理，機密會議請自行評估。
讓辨識與翻譯把公司/產品用語寫對。
會在講話停頓處自動切段；連續講不停時最多這麼長切一刀。短 = 字幕快；長 = 句子完整、翻譯較好。
對方講話沒被抓到就調高；一直抓到雜音就調低。
「我（麥克風）」用 Chrome 語音辨識時，翻譯優先用 Gemini；沒填金鑰會改走免費 Google 翻譯（本機版經伺服器代理，GitHub Pages 版直連）。

🔑 請輸入 Gemini API 金鑰

聽「對方」的聲音、AI 會議摘要都需要它。
還沒有？到 Google AI Studio 用 Google 帳號登入 → Create API key（Gemini Pro 訂閱不等於 API 金鑰，要另外按這裡申請）。
金鑰只存在這台電腦的瀏覽器，不會上傳到網站或 GitHub。

❓ 怎麼在 Google Meet 用

  1. 先按 ⚙️ 設定 貼上 Gemini API 金鑰（聽對方聲音必須）。
  2. 在 Chrome 另一個分頁開好 Google Meet 並進入會議。
  3. 回到這裡按 ▶ 開始記錄。Chrome 會問要分享哪裡 → 選 「Chrome 分頁」→ 選 Meet 那個分頁，並確認 「同時分享分頁音訊」有打勾，按分享。
    （只是拿聲音，畫面不會被錄也不會傳出去。）
  4. 你自己的聲音走麥克風；對方的聲音走 Meet 分頁音訊。兩邊分開記，所以能標出「我 / 對方」。
  5. 按 📺 浮動字幕，會跳出一個永遠在最上層的小視窗，切回 Meet 也看得到翻譯。
  6. 結束後按 🧠 AI 會議摘要 產生中英摘要、決議、待辦，再 💾 匯出 成 Markdown / 文字檔。

小提醒

  • 請戴耳機：用喇叭時麥克風會再收到對方聲音，逐字稿會重複。
  • Zoom / Teams 桌面版：分享時改選 「整個螢幕」並勾「分享系統音訊」。
  • 「我」用 Chrome 語音辨識：字幕最即時、免費，但一次只能一種語言（上方切「我說中文 / I speak English」）。中英夾雜很多就改用 Gemini 引擎。
  • 逐字稿會自動存在這台電腦的瀏覽器，不小心關掉重開還在；按 🗒️ 新會議 才會清掉。
  • 每列滑過去可以 ✏️ 修正原文、🔁 重新翻譯、🗑 刪除。
